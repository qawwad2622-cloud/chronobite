# ChronoBite-3D 🕰️🍔

مطعم آلة الزمن التفاعلي - سافر عبر الزمن وتذوق التاريخ

### **الفكرة**
موقع ويب تفاعلي لمطعم بتغير ستايله وموسيقاه ومنيوه حسب السنة اللي بتختارها. 
من 1950 الكلاسيك لحد 2100 الهولوجرام. وكل صنف اله مجسم 3D بتقدر تلفه وتكبس على مكوناته.

### **المميزات**
- **السفر عبر الزمن**: 10 حقبات مختلفة 1950 - 2100
- **منيو 3D تفاعلي**: همبرجر، بيتزا، شاورما، ميلك شيك
- **موسيقى حسب الحقبة**: جاز، بوب، سايبر، موسيقى فضاء
- **خلفيات متحركة**: بتتغير مع كل سنة
- **معلومات المكونات**: اكبس على اي جزء بالمجسم بعطيك تفاصيله

### **التقنيات المستخدمة**
- HTML5, CSS3, JavaScript
- Three.js للـ 3D
- Web Audio API للموسيقى

### **كيف تشغله**
1. نزل الملفات 
2. افتح `index.html` على المتصفح
3. اختار سنة من الشريط الزمني واستمتع
